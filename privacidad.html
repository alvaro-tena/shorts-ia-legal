Política de privacidad

Última actualización: 3 de noviembre de 2026.

1. Qué es shorts-ia

shorts-ia es una herramienta personal de escritorio. Sube vídeos creados por su propietario a las cuentas del propio propietario en YouTube, TikTok, Facebook e Instagram, y los programa a una hora concreta.

No tiene usuarios externos ni ofrece servicio a terceros.

2. Uso de los servicios de API de YouTube

shorts-ia usa los servicios de API de YouTube (YouTube Data API v3, método videos.insert). Al autorizar la app aceptas:

  • Las Condiciones del Servicio de YouTube.
  • La Política de Privacidad de Google.

3. Datos a los que accede y para qué

  • Permiso OAuth youtube.upload: solo para subir y programar los vídeos del propietario en su canal.
  • Token de actualización OAuth: permite subir sin volver a iniciar sesión.
  • Identificador del vídeo publicado y hora de publicación: para saber qué se ha publicado.

No lee comentarios, estadísticas, suscriptores ni ningún otro dato del canal o de otros usuarios.

4. Uso de las API de TikTok

shorts-ia usa Login Kit y la Content Posting API de TikTok (Direct Post). Al autorizar la app aceptas las Condiciones del Servicio de TikTok y su Política de Privacidad.

  • Permiso user.info.basic: nombre visible, usuario y foto del creador, para mostrar en qué cuenta se va a publicar.
  • Permiso video.publish: publicar en la cuenta del creador los vídeos que él aprueba uno a uno en el panel local, con la privacidad e interacciones que elige.
  • Token de actualización OAuth e identificador abierto (open_id): para publicar sin volver a iniciar sesión.
  • Identificador y estado de la publicación: para confirmar que el vídeo se ha publicado.

No lee vídeos, comentarios, seguidores, mensajes ni datos de otros usuarios.

5. Uso de las API de Meta (Facebook e Instagram)

shorts-ia usa la API de páginas de Facebook y la API de Instagram para publicar los vídeos del propietario en su propia página y su propia cuenta de Instagram. Solo se usan las cuentas del propietario de la herramienta.

  • Permisos pages_show_list, pages_read_engagement, business_management: localizar la página del propietario y la cuenta de Instagram vinculada.
  • Permisos pages_manage_posts, instagram_basic, instagram_content_publish: publicar los vídeos en esa página y esa cuenta.
  • Token de acceso de la página e identificadores de la página y de la cuenta de Instagram: para publicar sin volver a iniciar sesión.
  • Identificador y enlace de cada publicación: para confirmar que se ha publicado.

No lee mensajes, comentarios, seguidores ni datos de otros usuarios.

6. Dónde se guardan y con quién se comparten

Los datos se guardan solo en el ordenador del propietario: los tokens en credenciales/youtube.json, credenciales/tiktok.json y credenciales/meta.json y el historial en historial.csv. No hay servidores propios.

No se venden, ceden ni comparten con terceros. No se usan cookies, analítica ni publicidad.

7. Revocar el acceso

Puedes retirar el acceso en cualquier momento desde la página de permisos de seguridad de Google: security.google.com/settings/security/permissions. En TikTok: Ajustes y privacidad > Seguridad > Permisos de apps. En Facebook: Configuración > Integraciones comerciales; en Instagram: Configuración > Sitios web y aplicaciones. A partir de ese momento shorts-ia no puede subir nada.

8. Eliminación de datos

Para borrar tus datos, retira el acceso como se indica arriba o abre una incidencia en GitHub (ver Contacto). Al revocar el acceso, o si lo pides abriendo una incidencia, el token y el historial se borran del ordenador en un máximo de 7 días.

Los vídeos locales se borran automáticamente en cuanto cada plataforma confirma la publicación.
