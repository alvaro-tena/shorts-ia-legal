Interfaz de subida

shorts-ia es una herramienta de línea de comandos y no tiene interfaz web. El propietario la usa así.

Comandos

uv run pipeline.py conectar youtube frutinovela   # autorización OAuth (una vez)
uv run pipeline.py slots 3                        # próximas horas de publicación
uv run pipeline.py publicar-ahora                 # sube lo que toca (la tarea programada lo ejecuta sola)

Ejemplo de registro de una subida

[20:58:02] frutinovela_001: youtube -> videos.insert (privacyStatus=private, publishAt=2026-11-03T20:00:00Z)
[20:58:41] subida reanudable completada: 71.0 s, 38 MB
[20:58:41] programado: https://youtube.com/shorts/<id>

Código

El script completo de subida (redes.py) está adjunto a la solicitud de auditoría. Usa la subida reanudable de videos.insert con un token OAuth del propio propietario.
